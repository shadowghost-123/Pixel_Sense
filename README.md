# Face and Hand Recognition System

A real-time computer vision project built using **Python**, **OpenCV**, and **MediaPipe** to detect faces and hands from a webcam. The system identifies facial landmarks and hand landmarks in real time, showcasing the use of AI-powered computer vision for human-computer interaction.

## 🚀 Features

* Real-time face detection
* Real-time hand detection
* Facial landmark detection
* Hand landmark tracking
* Live webcam processing
* Fast and lightweight implementation

## 🛠️ Tech Stack

* Python
* OpenCV
* MediaPipe
* NumPy

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Face-and-Hand-Recognition.git
```

2. Navigate to the project folder:

```bash
cd Face-and-Hand-Recognition
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Run the project:

```bash
python main.py
```
